
# Third-Party Cyber Risk Analytics Dashboard

## Overview
A demonstration project that analyses synthetic third-party vendor
assessment data using Python, pandas, and Power BI.

## Objectives
- Validate vendor assessment data.
- Calculate illustrative, rule-based risk scores.
- Identify vendors requiring further review.
- Visualise risk levels and remediation findings.

## Tools
- Python
- pandas
- Power BI Desktop

## Workflow
1. Load the synthetic vendor dataset.
2. Check missing values, duplicate IDs, and invalid findings.
3. Calculate risk scores and risk levels.
4. Export the analysed data to CSV.
5. Explore vendor risks in Power BI.

## Dataset
All vendor records are synthetic and intended for demonstration
purposes only. They do not represent real organisations or
actual cybersecurity assessments.

## Limitations
The risk scoring model is illustrative and is not an official
cybersecurity standard. It should be validated before any
real-world use.
